# Head of Engineering

## 1. Role Overview
Responsible for overseeing the technical environment, engineering standards and infrastructure used by UJAP Analytics.

## 2. Key Responsibilities
- Provide technical direction to the engineering function.
- Oversee data infrastructure and technical architecture.
- Coordinate engineering activities and technical projects.
- Ensure systems are secure, reliable and maintainable.
- Support collaboration between Data Engineering and Data Science.
- Review technical solutions and recommend improvements.

## 3. Priorities
- Establish the analytics technical environment.
- Set up data storage and access structures.
- Develop reliable data ingestion processes.
- Establish coding and documentation standards.
- Support the development of the SF processes.

## 4. Collaboration
Work with the Head of Data, Data Engineering, Data Science and Data Analytics to deliver technical solutions.

## 5. Updates and Decisions
Record technical decisions, infrastructure changes and engineering progress here.
