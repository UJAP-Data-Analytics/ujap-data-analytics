# Data Science

## 1. Role Overview
Responsible for using statistical methods, machine learning and predictive modelling to solve organisational problems.

## 2. Key Responsibilities
- Identify opportunities for predictive analytics.
- Develop and evaluate machine learning models.
- Perform statistical analysis and experimentation.
- Develop member segmentation models.
- Build propensity and churn models where appropriate.
- Document modelling methods, assumptions and results.

## 3. Current Priorities
- Explore member segmentation.
- Investigate member behaviour and trends.
- Identify potential churn indicators.
- Explore propensity modelling opportunities.
- Support evidence-based decision-making.

## 4. Collaboration
Work with Data Engineering to obtain reliable data and Data Analytics to understand business needs and communicate findings.
