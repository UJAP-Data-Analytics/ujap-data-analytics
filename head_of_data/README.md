# Head of Data

## 1. Role Overview
Responsible for overseeing the UJAP Analytics function and ensuring that data initiatives support the organisation's objectives.

## 2. Key Responsibilities
- Provide direction to the analytics function.
- Coordinate the Data Engineering, Data Science and Data Analytics functions.
- Identify and prioritise data projects.
- Ensure responsible use of organisational data.
- Monitor project progress and team performance.
- Report progress and findings to the relevant leadership structures.

## 3. Current Priorities
- Establish a central data repository.
- Improve data collection and management.
- Develop the SF Master Dashboard.
- Support data-driven decision-making.

## 4. Collaboration
Work with the Head of Engineering, Data Engineering and Data Analytics to ensure that projects are properly planned and delivered.

## 5. Updates and Decisions
Record important decisions, project priorities and progress updates here.
