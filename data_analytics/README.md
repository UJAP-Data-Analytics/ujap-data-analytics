# Data Analytics

## 1. Role Overview
Responsible for analysing organisational data and turning it into useful insights that support decision-making.

## 2. Key Responsibilities
- Explore and analyse available data.
- Identify trends, patterns and anomalies.
- Develop reports and dashboards.
- Monitor organisational performance.
- Translate findings into practical recommendations.
- Support data-driven planning and decision-making.

## 3. Current Priorities
- Analyse SF transactions and existing member data.
- Support the development of the SF Master Dashboard.
- Explore member participation trends.
- Support finance and resource analysis.
- Identify gaps in existing data.

## 4. Collaboration
Work with Data Engineering to ensure data quality and Data Science to support advanced analysis and modelling.
